# Smart Budget Calculator

A modern, feature-rich budget calculator application built with Python and Tkinter. This application helps users track their income, expenses, and savings goals while providing smart financial analysis and recommendations.

## Features

- **Income Tracking**
  - Multiple income sources
  - Monthly income total calculation
  - Income history tracking

- **Expense Management**
  - Categorized expenses
  - Monthly expense tracking
  - Visual expense distribution (pie chart)
  - Expense-to-income ratio analysis

- **Savings Goals**
  - Set multiple savings goals
  - Track progress towards goals
  - Monthly contribution planning
  - Progress percentage calculation

- **Smart Analysis**
  - Net income calculation
  - Savings potential analysis
  - Budget health indicators
  - Personalized recommendations
  - Visual expense breakdown

- **Data Management**
  - Automatic data saving
  - Data persistence (JSON storage)
  - Easy data recovery
  - Secure local storage

## Installation

1. Clone the repository:
```bash
git clone <your-repository-url>
cd budget-calculator
```

2. Install the required dependencies:
```bash
pip install -r requirements.txt
```

## Usage

1. Run the application:
```bash
python budget_calculator.py
```

2. Using the application:
   - Add your income sources in the "Income" tab
   - Add your expense categories in the "Expenses" tab
   - Set your savings goals in the "Savings" tab
   - View analysis and recommendations in the "Analysis" tab

3. The application will automatically:
   - Calculate your net income
   - Track your savings progress
   - Provide budget recommendations
   - Save your data when you close the application

The application saves all data locally in a `budget_data.json` file. This includes:
- Income sources
- Expense categories
- Savings goals
- Last update timestamp
